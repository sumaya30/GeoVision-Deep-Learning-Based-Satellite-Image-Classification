# GeoVision — Deep Learning-Based Satellite Image Classification

A deep learning-based satellite image classification system for land-cover
and disaster classification using trained deep learning models.

---

## 🛰️Overview 

GeoVision is a deep learning-based satellite image classification project
developed to classify satellite images for two tasks: **land-cover
classification** and **disaster classification**.

The system uses trained deep learning models to analyze uploaded satellite
images and provide classification predictions with confidence information
through an interactive Streamlit application.

---

## ✨ Key Features

- 🛰️ Satellite image classification
- 🌍 Land-cover classification using ResNet18
- 🌪️ Disaster classification using ViT-B16
- 📊 Prediction confidence and probability visualization
- 🖥️ Interactive Streamlit-based application

---

## 🔗 Datasets

### 🌍 Land Cover Dataset

- **Source:** [EuroSAT Dataset on Kaggle](https://www.kaggle.com/datasets/apollo2506/eurosat-dataset)

### 🌪️ Disaster Dataset

- **Source:** [Disaster Damage 5-Class Dataset on Kaggle](https://www.kaggle.com/datasets/sarthaktandulje/disaster-damage-5class)

## 📦 Trained Models

The trained model weights are hosted separately on Hugging Face.

- **ResNet18** — Land Cover Classification
- **ViT-B16** — Disaster Classification

**Models:** [GeoVision-Satellite-Image-Classification](https://huggingface.co/sum3010/Geovision/tree/main)
